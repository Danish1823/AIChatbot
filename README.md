# AI Chatbot 🤖

A full-stack AI chatbot built using React.js, Flask, Python, and Google Gemini API.

## 🚀 Live Demo

https://ai-chatbot-gilt-sigma.vercel.app

## 📂 GitHub

https://github.com/Danish1823/AIChatbot

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- CSS

### Backend
- Python
- Flask
- Flask-CORS
- REST API

### AI
- Google Gemini API

### Deployment
- Frontend: Vercel
- Backend: Render

### Tools
- Git
- GitHub
- VS Code

## ✨ Features

- AI-powered conversations
- Real-time responses using Google Gemini
- React-based chat interface
- Flask REST API
- User and AI message history
- Loading state while AI is responding
- Error handling
- Responsive interface
- Secure API key management using environment variables
